### ⚡ [Task Flow Engine](https://github.com/sanyalovemoney/task-flow-engine)

- **High-Throughput Streaming ETL Pipeline:** Processed 1GB+ CSV datasets (~7M rows) with minimal memory footprint using `fs.createReadStream` and partial-line-aware custom transform streams.

- **Reactive Alert System & Auth Proxy:** Designed an event-driven alert system with colorized terminal logs and Telegram payload simulations, paired with an extensible authentication proxy (API Key, JWT, OAuth2).
